# 人物、腔调与对白

技法源自《游戏入侵：抢男女主机缘会上瘾诶》(猫不秃)的逆向拆解。女主为重生复仇 + 独狼流，作者自陈"不是无情人设""不是无私奉献型""很多女反派/对手，我喜欢写"。

**核心判据**：主角不是靠"性格描写"立住的，是靠**七个行为规则**立住的。每个规则都能单独调用、单独生产桥段。

## 用法

- 设计主角 → §1
- 独狼/单人流没张力 → §2
- 写反派/对手 → §3
- 写女性对手 → §3.3
- 调叙述语气 → §4
- 写对白 → §5
- 新角色登场 → §6
- 配角没记忆点 → §7

## §1 主角人设：七个可复用零件

| 零件 | 定义 | 原文例证 |
|---|---|---|
| **伪装** | 情绪与行动完全脱钩，且**明写"她在演"** | `虞寻歌想现在就杀了她，但逃亡经历不仅教会了她忍耐，也教会了她伪装，她笑得比柳争流更亲热` |
| **忍耐（有额度）** | 能忍五百章，但额度用尽即刻爆破 | `忍一时风平浪静？不，她只知道，她忍了那一刻，从此就再也站不起来了。` |
| **记仇（拒绝速杀）** | 明确否定"一刀泯恩仇"的爽文捷径 | `一刀泯恩仇？不存在的……她不要向前看，她要向下看` |
| **务实/效率狂** | 一切行为按收益率排序，顺路完成 | `送信的路上顺手杀老鼠，买尸虫面包的路上顺手帮铁匠买酒` |
| **毒舌（含自嘲）** | 吐槽对象**包括她自己** | `你虽然偷东西抢东西还喜欢趴床底，但你可真是个好姑娘。` |
| **不圣母（但有底线）** | 自私是默认值，善行是例外并被自己嘲笑 | `她想要，她得到。她重生而来不是为了当道德标兵的。` |
| **边界感** | 不给建议、不作保、不欠人钱 | `我和定海合作得还行，但我不会为它作保` |

### 地基：把"独狼"写成创伤后遗症，而非性格偏好
> `她知道她从此以后，永生永世，都无法再相信任何人了。`
> `他们摧毁了她信任的能力。`
> `至亲之人都能将她背叛……那其他人呢，她如何敢信。`

这一段把独狼从性格偏好升级为**病理**，于是后面 1400 章不组队都合理，且每一次她破例信任都自带情感重量。

**做法**：在前 10 章内写一场"至亲背叛 + 账本对照"（承诺的 500 万 vs 密室里三百斤黄金），此后所有拒绝合作的行为都不必再解释。

### 创伤定义能力法
给主角的**每一项超常能力配一句"她是被什么逼出来的"**，能力便同时是伤疤，读者不会觉得挂开得突兀。

公式：`因为{惨痛经历}，她{现在的本能反应}。`

### 自私显性化 + 单一例外
先大声承认自私，再让她偶尔做一件好事，读者的好感度收益是纯善人设的三倍。

**每一次善举后 1–2 行内插入自嘲**，堵住"圣母"读感：
> `她真是良心未泯。`
> `虞寻歌拍了拍自己：你虽然偷东西抢东西还喜欢趴床底，但你可真是个好姑娘。`

### 忍耐额度可视化，爆破必须有代价
长期隐忍必须有一次"明知代价仍要动手"的爆发，否则人设从"能屈能伸"塌成"怜"。

**爆破点安排在主角最弱的时候**，并让她当场付出可量化的损失（丢 7 点智力、献祭一个技能）——爽度与痛感同时拉满。

### 效率狂人写法：一切行为"顺手"化
主角的强不靠天赋描述，靠**行程密度**呈现。任何一场任务里塞进 2–3 个次要收益动作，用"顺手 / 顺路 / 见缝插针"三个词连接。

> `只是偶尔有陌生客人进店里她才会停两秒顺手偷一下`
> `向码10公里外的梁家跑去，就当见缝插针锻炼身体了`

### 偏执细节法（反侥幸）
写主角的谨慎要具体到近乎强迫症，读者才会信她能活 1400 章。

> `戴上口罩，又用泳帽将自己的头发全部包裹住，保证不会掉落一根头发丝儿`
> `她宁愿自己像个智障，也不会在干了坏事后还回自己老窝`

每次犯罪/潜入后写一段"销毁流程"（烧衣服、铲土、换城市、洗手液去血腥味）。这些段落也天然是**节奏缓冲带**。

## §2 独狼流的五条人际张力管线

没有固定队友，用五条管线补位，**任何一章至少开着两条**：

1. **一次性配角，靠一句台词报废**
   司机小吴四行完成全部生命周期：
   > `"两小时内到家，我再给你两千奖金。"` → 疯狂飙车 → `"你来我这儿入职前是干吗的？"` → `"跑灵车的。"` → `"……"`

2. **敌人链（永不断供）** — 凡人级 → 同代 → 跨维度 → 神级。每一层敌人淘汰上一层，**旧敌人不删号，改为降级复用**（死敌梁鱼川后期变成骚包网友）。

3. **系统/技能文本当对手** — 技能说明本身写得像人在说话（`小偷才会拒绝贪婪`），主角与面板之间形成拌嘴关系（`真是恶心他妈给恶心开门！`）。

4. **群聊与舆论场** — 独狼群【世界末日也要坚持玩单机】、家庭群、粉丝对线。用饭圈生态生产零成本笑点：
   > `图蓝天天在网上说虞寻歌对她很好很好，但在图蓝的唯粉眼里，这就是虞寻歌的毒唯`

5. **观众席** — 解说与观众像体育解说一样点评主角的作战风格。**观众替读者说出评价，作者不必自夸主角。**

### 常驻搭子的定位：契约宠物，不是队友
身份上低一级、感情上平等，既保住独狼标签，又提供日常对手戏：
> `她们是平等契约，她有权力拒绝虞寻歌的召唤`

**规定每 3–4 章至少一次章末私聊收尾**，用它在高压章末做软着陆。私聊用 `「」` 与正文对话 `""` 视觉区分。

## §3 反派与对手

### 3.1 反派魅力 = 真投入 + 假账本
让反派**确实付出过、确实救过主角**，"该死"由**收益结构**而非行为恶劣度决定。

> `每一次从自己这里获得利益的前后，他们都会出点血……可她如今回想起来，她几次濒死，都是在躲过几次小危机后……`

把 PUA 写成**技术分工**：
> `低段位的压榨是全家一起PUA，高段位的压榨都是组合拳，一个人负责打一个人负责疗伤一个人负责端茶倒水让她缓口气儿。`
> `虞清山和虞寻欢就像最顶尖的钓鱼好手，他们要大鱼，就会给上好的饵料，时不时还会放长鱼线让鱼儿放松警惕。`

**做法**：为家庭型/情感型反派做一张"付出—索取"对照表，让主角在某一章**亲手把它算出来**，那一章就是全书最狠的爽点。

杀伤力最大的台词往往是最日常的一句：
> `我教过你多少遍了，遇到问题冷静，不要撒气，撒气是女人才会干的事。`

### 3.2 强者残忍要"具体且从容"
威胁的恐怖来自**选项的可选择性**，不是音量。

> `你要是回空间，我就让你的主人在死前受尽痛苦与侮辱！让我想想，围着绿洲像狗一样爬怎么样？还我亲自给她挑个种族交配？`
> `啊不知道你们载酒星的文明在不在乎这个……那剃掉所有头发？？挖掉翅膀？`
> `想表现你那可怜的勇气，让自己看上去还有尊严？不会吧哈哈哈，你不会以为弱者有尊严这种东西吧？`

让反派**一边写字/喝茶/挑选，一边列举羞辱菜单**，动作与内容的落差即恐怖来源。

对照：主角的回击只有六个字 —— `我只是赶着复仇。`
**强者话长（羞辱需要展开），弱者话短（短即未崩）。**

### 3.3 女性对手的三条通则
女性对手**从不因为爱情而降智，也不被写成花瓶或纯恶**：

1. **动机不挂在男人身上** — 是权力/资源/胜负欲
2. **伤害方式制度化**（悬赏、通缉、断肢、断供）而非撕扯
3. **留一条"敬意/转化"出口** — 恨意可以回收，恶意不可以

范例：
- **梁鱼川**：`她不仅提出要活的，她还分别悬赏自己的四肢` —— 恶得有商业头脑；后期洗成戏精网瘾少女（`喝个咖啡都要用绿杯子，问网友，杯子和她的羽翼搭不搭`），完成从死敌到活宝的资源再利用
- **苏一瞳**：抢在男主之前转两千万，一步完成"宣示主权 + 羞辱 + 施恩"三件事；结局判词是 `她永远不会满足，永远不会甘心` —— **毁于欲望而非毁于恋爱脑**
- **终极对手**：不写外貌写压迫感 —— `她的眸光也充斥着战意，像被拉到极致的弓，像绷紧的弓弦，当她望向你时，你会感觉自己被箭矢矄准。`

**作者的反派设计宣言**（值得抄在稿纸上）：
> `如果说逐日的狂傲张扬让讨厌她的人和喜欢她的人一样多，那荒烬的谦逊和慎言让她收获的喜爱与包容远远大过厌恶。……激烈的爱与恨留下的刻痕远比普通的喜爱来得深刻。`

### 3.4 敌人分层不断供 + 旧敌降级复用
每卷设一个"当代最强敌"，**上一卷的敌人降为本卷的资源/喜剧角色**，保留其原有性格特征（梁鱼川始终"极端"，只是极端的对象换了）。读者的投入不浪费。

## §4 叙述腔调：第三人称限知 + 弹幕化内心

### 十二句范本

| 原文 | 句式机制 |
|---|---|
| `然而她一个帅气的鲤鱼挺身，无事发生……` | 郑重动作 + 四字冷冰冰结果 + 省略号自嘲，**反高潮** |
| `好好好，想要赶时髦又碍于规矩不能写骨科你就这么恶心人是吧？！` | 网络语气词起句 + 长定语 + "是吧？！"，**破防独白直插叙述** |
| `不情有可原也没办法，她自己的猪脑，自己宠。` | 短句三顿，**自嘲代替自怜** |
| `5分钟前：当小偷不好吧？` / `5分钟后：我就要！！！` | **表格式对照句**，两行完成人格反转 |
| `床上的人小脸通黄，床底的人那是小脸白得像死了三天。` | 对仗 + "那是"口语提顿，**空间对照制造喜剧** |
| `这是神赐天赋吗？这是神赐予你诅咒！` | **同词反转反问**，一问一答自答 |
| `世界不是围着虞寻歌转的，但世界一定是围着男女主转的。……太棒了，就她这个男主姐姐不是。孤立她是吧！！` | 先格言化陈述，**再突降为撒泼** |
| `经常杀人的朋友都知道……普通人处理争端的想法是：要不还是算了吧。杀过人的人……：要不还是杀了吧。` | 伪科普腔 + 排比对照，**用生活化句式讲反社会内容** |
| `虞寻歌：奈斯啊！！五十斤黄金没白花！！！` | **"人名+冒号"直出心声**，绕过"她心想" |
| `小虞寻欢，就这样被腰斩。` | 独立成段短句，**书面语正经词配下流内容** |
| `令人心酸的是，灰谷的浓雾屁用没有，但金色丘陵的【金波利】每100克就能卆10个金币。` | 严肃转折词 + 粗口，**语域碰撞** |
| `虞寻歌会养龙吗？她根本不会！！她养的明白吗？她明白个屁！` | 自问自答×2，递进式否定，**梗结构** |

### 五条共性
- 句子平均极短，**一个逗号一个信息点**
- 高频口语标记：`是吧？！` `……` `！！！` `那是` `我请问` `好好好`
- 心理独白**不加引导语**，直接顶进叙述层，人称在"她"和隐性"我"之间自由滑动
- **每一个煎情段落后 1–3 行内必有一句自嘲收尾**（哭完立刻接 `今天才25号，虞寻歌只觉得自己比狗都忙`）
- 全书 `？`(15143次) **多于** `！`(10585次) —— 主要靠**内心反问**推情绪，而非感叹

### 叙述层三段落差（本书腔调的最小单位）
```
正经陈述 → 突然口语 → 自嘲收尾
```
**每 3–5 个自然段安排一次落差。**
降落词库：`屁用没有 / 我请问 / 是吧？！ / 好好好 / 那是 / ……`

### 心声直出（去引导语）
删掉"她心想"，用 `人名：` 或独立成段的短句直出，等于给叙述加弹幕：
- 吐槽用 `人名：` — `虞寻歌：？`
- 判断用独立短句 — `小虞寻欢，就这样被腰斩。`
- 情绪爆发用 `？！` 或纯符号 — `虞寻歌：˙ꩊ˙ ？`

**此格式一章不超过 5 次，否则失效。**

## §5 对白技术

### 核心自检：对白三职能
每一句台词**至少同时完成两件事**，否则删：**推进交易 / 暴露性格 / 埋伏笔**。

写完一段对话，逐句标注职能；只完成一件事的句子并入相邻句或删除。

范例：`这是交易还是请求？` —— 推进（逼对方定性）+ 性格（挑衅）+ 伏笔（后文改名）

### 三段拆解

**段一：家庭战场——每句台词都在争夺一个第三方的判断**
```
虞寻欢："姐，你是不是不高兴我结婚啊？"        ← 当着未婚妻构陷姐姐，一句完成挑拨
虞寻歌："怎么会？我当然高兴。"                 ← 拒绝入套，语气过于平静反而更真
虞寻欢："那你最近为什么……"                    ← 半句话施压，留白逼供
虞寻歌："我是真的替你和一瞳高兴，只是……失业了" ← 用可验证的坏消息替换动机
（举出银行APP三千万）                            ← 物证收尾，切断继续追问
苏一瞳转两千万："这是我和寻欢给姐姐的零花钱。"  ← "我和寻欢"四字宣示所有权
虞寻歌："我手机里有虞寻欢从小到大的照片……
        发给你后我这边会删掉，以后这些照片全世界只有你有！"
                                                 ← 顺着对方的占有欲加码，一击拆散男女主
```
**技术点**：全场没有一句吵架，所有攻击都伪装成祝福与示弱；真正的胜负手是主角**顺着敌人的心理需求供货**。

**段二：强弱悬殊谈判——用最短句子做最大让步与最硬拒绝**
```
虞寻歌："我们去找蓝色王座吗？"      ← 主动提供价值，不求情
鲨冷："走。"……"你会多少种语言？"    ← 强者只用单字与提问
虞寻歌："669种。"                    ← 报数字，不解释，数字即议价筹码
鲨冷："出去后帮我翻译游戏规则，我护你一段路。"
虞寻歌："可以。"
……
鲨冷："你不会以为弱者有尊严这种东西吧？"
虞寻歌冷冷说道："我只是赶着复仇。"   ← 六个字，既回避羞辱又预告杀招
```
**技术点**：最后一句**台词与动作同步**——话音落时技能已发动，对白直接承担战斗节拍。

**段三：喜剧车轱轱——用重复制造性格**
```
虞寻歌："所以你的神明天赋词是什么？"
由我："……你这人有没有情趣会不会聊天？"
虞寻歌："……姐，我还没死，我赶时间，等我以后死了埋这里，我可以陪你聊一整年。"
由我："……我理解欺花了。"
虞寻歌："我暂时还不是很理解，所以你的神明天赋词到底是什么？"
……
"那就去分析。" / "你不告诉我我怎么分析？" / "那就去找。"
```
**技术点**：① 省略号单独承担一个"表情包"功能；② 角色性格由**拒绝的方式**定义；③ 喜剧节奏靠"主角完全不接对方的情绪，只推进目标"。

## §6 人物出场四拍模板

```
{名号/外号}——{一句能力或气质比喻}。
{一件已完成的、代价明确的行为}。
{危险等级：数值 / 后果 / 主角的生理反应}
```

对照范例：
- **梁鱼川**：`走得是刺客路线，在雨天宛如杀神，一步一人，谁也摸不清她会在哪一滴雨里出现，人称刺客之神` → 悬赏虞寻歌四肢并按肢体分别标价 → S级【水神】，"太难杀了"
- **鲨冷**：等级先行（`最低7阶，最高就是鲨冷，19阶`）→ 一脚踏出荆棘巢穴 → `每一次和鲨冷接触说话，她都有种寒毛直竖的恐怖之感`
- **熊泥**（只出现一章却极难忘）：`听说秋熊熊泥的手艺才是全族最好的那一位` → `总计已经制作了三百多万罐蜂蜜`，且**自己从不吃** → 动机一句话：`这是我给它们准备的回家礼物。`
- **终极对手**：跳过外貌，直接写压迫感

**注意**：等级不必是数字，也可以是**后果**或**一个外号**（沈玉食被街坊叫"香香"），一个外号即完成温度定性。

### 一次性配角四行法
```
需求（给钱）→ 超额完成 → 一句反常台词揭示身份 → 主角"……"作结
```
路人不必有弧光，但必须有**一个笑点或一个信息点**，之后立刻扉掉。

## §7 记忆点安装法：四类挂件

**新角色登场时同时安装两件——一句可复读的台词 + 一个可携带的物件**；此后每次出场至少触发其一。

1. **技能名即台词** — 【甲来！】【我要这个这个和这个】【啊，我那个怎么不见啦】【我明明可以直接抢】。技能面板承担了主角 30% 的性格塑造，且每次释放技能 = 重复一次口头禅。

2. **道具即人格** — 猫窝【喵喵旅社】→ 后院猫群 → 【新年快乐】"紧握该奇物，**大声'喵'一下**"；铃铛诅咒把训练量化成声音。

3. **口头禅 + 复读机** — 机车每次都是"我刚换的金属涂层，每毫升两千金币"（跨三章重复三次）；复读段子 `"有什么必要吗我请问？"` / `"行行好！你能别重复废话了吗？"`

4. **模板台词的反差揭穿** — 露琪亚对**每个**学生说同一句"虽然我只给你上了几节课，算不上你的老师，可我为你感到骄傲"。一句话既立"金牌导师"人设，又立刻用重复把它变成笑话。

**对"高人"角色，安装第三件：一个会被拆穿的习惯**（模板台词、口头禅）。拆穿的那一刻即该角色的**第二次塑造**。
