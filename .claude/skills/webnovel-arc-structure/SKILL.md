# 长篇结构：副本、伏笔与主线控制

技法源自《游戏入侵：抢男女主机缘会上瘾诶》(猫不秃, 1458章/91086行)的全书骨架测绘。

**最反直觉的发现：作者不维持主线，作者换挡主线。**

## 用法

- 规划全书大纲 → §1 骨架配比
- 设计一个副本 → §2 九环节 + §3 防重复
- 写副本结算 → §4 六件套
- 安排伏笔 → §5
- 主线动力衰减 → §6 换挡
- 卷末过渡 → §7
- 写结局 → §8

## §1 全书骨架配比

```
全书 1458 章
├─ 前期世界建立       ch1–373     (26%)  ← 主线A：复仇。密度前置，350章后退场
├─ 副本主体           ch374–1374  (69%)  ← 主线B：世界存亡 → 主线C：纪元
│   ├─ 副本内章 820 (56%)
│   └─ 间章   181 (12%)   ← 13 段，每段 13–32 章，中位 20
└─ 终局+收尾         ch1375–1458 (5%)
```

**副本内章 : 间章 ≈ 5.6 : 4.4** —— 接近黄金配比。副本内章比间章长约 13%。

## §2 副本的九环节标准结构

以第一个副本（8 章）为标本，此后 1000 章全部复用这个骨架：

| 环节 | 占比 | 原文例证 |
|---|---|---|
| **①进入前准备** | 1章 | 装备取舍、拼门票 |
| **②资格播报** | 半章 | `——【欢迎载酒星玩家虞寻歌首次激活进入世界战场的资格】` `【倘若超过60天未参与神明游戏，将永久丧失游戏资格】` |
| **③规则说明（明牌+暗牌）** | 1.5章 | 三条规则**只给读者看懂一条**，其余用乱码留白 |
| **④定位（天梯榜）** | 半章 | `82679┃寻歌┃载酒·人族┃2阶傻瓜┃无` —— 一行字建立全书最重要的"落差刻度" |
| **⑤探索+结盟** | 2章 | 用 669 种语言换强者保护；**副本内嵌套小游戏** |
| **⑥危机** | 2章 | 被点为执旗者、遭遇 19 阶强者；宠物被抽血刮鳞 |
| **⑦翻盘** | 1章 | `——【我明明可以直接抢】！！！` → `【窃取进度67%，窃取中断！】` |
| **⑧结算/收益** | 3章（在间章） | 新天赋四技能全文 + 道具升级 + 公开诅咒公告 |
| **⑨钩向下一副本** | 半章 | **敌方视角反应**——用受害者的痛苦把爽点二次兑付，同时立下跨卷死仇 |

### 七步进本模板（固化播报，每次原样重跑）
1. 装备/技能盘点与取舍
2. 拼门票 → `——【欢迎…进入世界战场】`
3. **解锁清单**：逐条对应一项权限
4. **专属规则**（难度自适应器）
5. 天梯榜定位
6. 规则明牌/暗牌
7. **队友/对手悬念收尾**

### 四条副本设计规则

**R1｜教学关先跑通全流程**
第一个副本的唯一任务不是好看，是把此后所有副本的九环节**一次演示完**。
**首个副本控制在 6–10 章**，宁可牺牲深度也要保证结构完整；后续副本可以拉到 100+ 章，因为读者已经内化了节奏。

**R2｜规则明牌 = 爽点，暗牌 = 悬念，按 1:2 配比**
全给读者看懂就没有危机，全看不懂就没有参与感。
规则总数 N，**明牌约 N/3～N/2**；暗牌用乱码/异族文字视觉化，读者第一眼就知道"这里有雷"。
实测：3 条规则译出 1 条；27 条规则译出 15 条。

**R3｜违规必须当场扣血、可量化**
> `【嘟——你违反了一条游戏规则，将随机抽取神罚】` / `【神罚抽取完毕，你失去了4点体质】`

惩罚必须扣**读者已被教会珍惜的数值**（属性点/技能），不要扣抽象的"生命"。

**R4｜天梯榜：把落差写成一行字**
一行排名比一千字心理描写更能建立"我很弱"：
> `1.萄柚┃紫川·语果┃19阶霸主┃呼吸有害`
> `82679┃寻歌┃载酒·人族┃2阶傻瓜┃无`  ← 末位第二，称号栏是"无"

每个副本开场必须插入一次可排序的量化定位；末尾对照同一榜单，**涨幅即爽点**。

## §3 百章级副本如何不重复：五个换轴 + 一个嵌套

**从不换"进本—规则—翻盘—结算"这个骨架，只换轴：**

| 换什么 | 实例 | 效果 |
|---|---|---|
| **换玩法类型** | 临摹画作 / 竞速 / 采矿 / 经营餐厅 / 建造 / 大逃杀 / 世界巡游 / 擂台赛 | 每个副本对应一个**现实小游戏原型**（胡闹厨房、我的世界、跑跑卡丁车），读者零成本理解规则 |
| **换阵营/队友结构** | 独狼 → 随机四人组 → 学院班级 → 代理人契约 → 跨世界联军 | 强制刷新人际张力，避免配角疲劳 |
| **换目标函数** | 完成度排名 / 营业额 / 积木数量 / 存活时间 / 胜场 / 权柄 | 结算口径变，爽点形态就变 |
| **换身份与尺度** | 226 章直接把主角塞进另一个世界当**学院学徒**，整卷改写为校园成长文 | 最激进，也是全书最长的一卷 |
| **换对手层级** | 2阶傻瓜 → 19阶霸主 → 神明玩家 → 高维种族 | 天梯榜作为可视化标尺，每次抬一档 |

### 大副本 = 小副本串联（百章篇幅不塌的技术底座）
**每 15–25 章插入一个"关中关"**，自带独立的规则/胜负/奖励，重启读者的短期期待。

实证：小画家副本内套「王与王座」五轮夺旗赛；玩家遗物明写三阶段；埋骨之地二阶段。

### 专属规则 = 难度自适应器
主角变强后副本会失去张力，用"针对你的额外规则"给强者上镳铐：
> `【检测到载酒寻歌潜力及破坏性已达危险线，现开启专属限定规则一阶段】`
> `【专属规则三：禁止对机械族使用翻新技能】`

**把主角的成长直接换算成规则条数**（2阶3条 → 7阶27条 → 深渊45条），读者看到条数就知道她多强。

## §4 收益结算："发工资"六件套

**为什么不能省**：副本内主角一直在"支付"（丢属性、丢天赋技、宠物受伤）。
**结算是唯一的收支平账时刻；不平账，读者的沉没成本会转成弃书。**

作者把结算写成三章级的独立段落。六类收益一件不少：

| 类型 | 例证 | 作用 |
|---|---|---|
| **①硬通货** | 9颗黄金树果实 / 3个霸主宝箱 / 1000属性点 | 数字爽感 |
| **②称号** | `【恭喜…获得永久称号：月亮邮差（唯一）】` | **兑现简介预告**，可长期携带的身份标签 |
| **③世界级福泽** | `载酒玩家神赐天赋下限提升至B级／人类寿命上限+100年` | 把个人胜利转成**集体收益**，制造"全世界欠她人情" |
| **④信息与权限** | `成为裁决后最大的收获就是她知道了很多普通玩家不知道的事` | 为下一卷解锁剧情通道 |
| **⑤人脉** | 队友冲进废墟大喊 `裁决！！你怎么了？` | 情感回报 |
| **⑥代价/负收益** | `【强制关闭载酒当前等级最高的2000个泽兰锚点】` | **让结算不是纯发糖**，同时生成下一段困境 |

**⑥ 是最容易漏的一项**：每次结算植入一条"这次赢了，但世界因此失去了什么"，它就是**下一卷的开局困境**。

### 进阶：评分曲线与终局撤仪式
```
73 → 88 → 99 → 99 → 99 → 100 → 100 → 【无结算】
```
仪式先建立十次，再在终局**故意撤掉**，用"没有奖励"表达"已超出这个奖励体系"：
> `没有被传回自己的世界，没有游戏结算，没有游戏奖励，也没有神明评分`
> `不，她只觉得天高海阔，这才是真正的脱离神赐`

### 用敌方视角二次兑付爽点
主角自述胜利只爽一次，写受害者反应能爽两次：
> `他直接给了自己一巴掌，为什么要去招惹那个新来的玩家……`
> `看着自己的面板越想越气，鲨冷又给了自己一巴掌……让你贱！`

**每个重大收获后配 300–800 字敌方/旁观者视角**，同时用它埋下一卷的仇恨线。

## §5 长线伏笔：埋与收

### 5.1 简介即伏笔清单，允许 15% 不兑现
作者在正文第 12 行一次性预告 **20 个称号**，全书用 1450 章逐一兑现。这是一份**公开的进度条**。

| 预告名号 | 兑现进度 |
|---|---|
| 【暴躁月亮】主人 | 13% |
| 战场聊天频道八卦中心 | 35% |
| 窝囊气球制造商 | 38% |
| 【猫的理想】船长 | 43% |
| 载酒裁决 | 62% |
| 月亮邮差 | 68% |
| 花花蝴蝶 | 70% |
| 【雪国回音】制作者 | 72% |
| 世界叹息书写者 | 75% |
| 沉默的饼干国王 | 88% |
| 星海的救世主／群山的大灾变 | 94% |
| 星海囚徒 | 97%（终章标题） |
| **永不兑现** | 机械族第二次大罢工 / 单机爱好者 / 不可占卜的神秘人 |

**兑现节奏：先密后疏再密**
- 前 40%：密集小兑现，**建立信任**
- 60%–75%：兑现改变身份的高价值三个
- 88%–97%：集中兑现定义结局的

**刻意留 2–4 个不兑现**，维持"世界比故事大"的感觉。

**做法**：开篇列 15–25 个称号/事件作为公开清单。

### 5.2 长线伏笔用"物"不用"言"
跨千章的伏笔靠对白记不住，靠**道具**能记住。每条长线配一个**可携带、可升级、可损坏的实物**。

**伏笔的回收写成"物的状态变化"，不写成人物的表白。**

四条实证长线：

| 伏笔 | 埋 | 收 | 跨度 |
|---|---|---|---|
| **未来的自己送纸条** | `她打开鞋柜时，发现里面有一张纸条——【不要选复活技】。是她的字迹` | 终局核心机制正是"回到过去书写历史" | ~1000 章 |
| **死仇** | 宠物被刮鳞 + 抢走 SSS 天赋 + 公开诅咒 | `要不是还不想死，鲨冷真想流着泪问一句，这到底是谁的技能库？`（**从死仇转为队友，仇恨变成笑点**） | 1072 章 |
| **宠物本源缺失** | `问题出在她丢失的龙血上…她的本源力量丢失了三分之一` + `只要你们不断胜利，她就能得到奖励，从而进化` | 每场副本自带"为它而战"的次级动机 | 全书 |
| **雪人** | `【夏日雪人·寻歌】（回档次数：10）` | 番外末句 `真巧，那个小雪人，刚好在昨天彻底融化了，对吧？` | 全书最后一次回收 |

注意最后一条：**用一个道具的物理状态（融化）替代"她回来了"的直白抒情。**

那张纸条还有一个即时闭环的用法——埋下去后**几十章内先小收一次**（主角回到过去给自己送纸条），把全书的因果模型提前 1000 章教给读者。

## §6 主线换挡（而非主线延续）

### 关键词密度实测（每万行）

| 行区间 | 虞寻欢(仇人) | 上辈子 | 裁决(新主线) | 逐日(新人物) |
|---|---|---|---|---|
| 0–1万 | **1368** | 225 | 1 | 0 |
| 1–2万 | 633 | 49 | 0 | 0 |
| 2–3万 | 40 | 12 | 0 | 0 |
| 4–5万 | 6 | 1 | 1 | 692 |
| 5–6万 | 0 | 1 | 16 | **915** |
| 8–9万 | 2 | 1 | **252** | 216 |

复仇主线**在前 2 万行（约 ch1–350）烧掉 90% 的用量，之后基本退场**，由"世界存亡"接棒，再由"新纪元"接棒。

### 换挡规则
- **每 400–500 章更换一次主线动机**
- **新主线必须在旧主线的高潮里诞生**（世界濒临破碎 → `载酒裁决！`）
- 旧主线留 **5% 密度**做怀旧回收（旧敌人在 8–9 万行区间回升，是**告别式回收**）

### 四台主线提醒器（换挡后旧关系不能断）

| 装置 | 全书次数 | 作用 |
|---|---|---|
| **天梯榜**（副本内实时排名） | 107 | 随时告知"我在哪、离目标多远" |
| **战场聊天频道**（跨副本社交） | 223 | 让副本外的角色在副本内说话，维持人物存在感 |
| **世界公告**（世界级广播） | 57 | 把个人成绩转成世界收益，重申"你为谁而战" |
| **副本光幕/直播**（外界观众） | 329 | 制造"被注视"的持续社会压力 |

**设计 3–4 个"任何场景都能自然插入的公共信息层"**，让不在场的角色每隔十几章冒一次头。

补充：**每场副本前的"专属规则"**也是主线提醒器——按主角当前破坏力动态加码，等于每次进本都复述一遍"你已经成长到什么程度"。

## §7 卷与卷的过渡：三段式接力（13–32 章）

**紧接高潮的休整期是全书情感浓度最高的窗口，不能压缩成一章。**

**第一段（1–3 章）：清账**
标题直白：「收获盘点」「盘点收获」「『玩家遗物』结束」「『换牌』游戏结算」

**第二段（8–20 章）：消费与建设**
把上一卷赚的钱花掉，同时铺设下一卷的资源与人物：「载酒理事」「载酒基建&技能修改」「六只副船长」「猫猫船，启航」
**这一段必须让主角"花钱"和"交朋友"**，否则收益无感。全书最动人的场面往往就在这里。

**第三段（1–3 章）：新悬念 + 仪式化标题接力**
```
「催她营业&洗牌」→「【世界墓林·抉择】&即将胡牌的玩家」→「谁在出千？」
→「那个不能说名字的神秘人」→「真心话&【一次解惑】」→「抹去镜上的雾」
→ 直接进本「神明游戏：积木与我1」
```

### 仪式化接力标题
每段间章的**末章**用同一个句式收口：
> 「第23164场神明游戏」／「第23166场」／「第23167场」……

这是全书最可复制的接力装置——**读者一看到这个标题就知道"下一章进本"**。

### 跨卷钩子的三种写法
1. **敌方视角钩** — 副本结束后用整段写敌人的崩溃与旁观者的推理
2. **版本更新钩** — 「游戏更新：《万族之劫：毁灭前奏》」「游戏3.0《无序星海：钟声响起》」
3. **倒计时钩** — 「第一声钟响」ch1120 →「第二声钟响」ch1190 →「第三声钟响」ch1281
   **跨 161 章的三段式倒计时，横穿三个副本**，是全书最有效的长线张力弦

## §8 结尾：五步收束，全部是"改写规则"而非"打死敌人"

1. **不杀反囚** — `祇得活着！` 反派被并入世界机制成为钟摆，从此**反派 = 世界规则的一部分**
2. **权柄结算** — 最后一次"发工资"发的是**权柄**：主角获得的是"发放游戏资格的权力"
3. **规则重写** — 给玩家 3 次重来机会、划分 PVP/PVE 区、把"诅咒"改成"邀请函"：`比如这份邀请可以是诅咒，也可以是改变命运的机会`
4. **代价可视化** — `她赌赢了，一次就成功…可她还是押上了赌注！` **主角在最后一刻仍在支付**
5. **不闭合的开机画面** — 最后一章不写结局，写**新版本公告**：
   > `【新增阵营：星海囚徒】` / `【深渊游戏12.0：未被邀请的客人】`

### 三处留白
- **明确拒绝收拢其他时间线**：`那是她的故事，我不会插手`
- **未答之问**：追问"你赌上了什么？" → `转了个身背对愚钝，表示自己拒绝回答`
- **番外把视角完全交给配角** — 全篇写配角如何在主角消失的七年里独自长大，全书最后一句用"雪人融化"完成主角的归来。**主角在自己的最后一句里不出场、不说话。**

### 终局撤仪式
建立任何仪式**至少十次**后，在终局**撤掉它一次**；结尾用"新规则上线"替代"故事结束"。
