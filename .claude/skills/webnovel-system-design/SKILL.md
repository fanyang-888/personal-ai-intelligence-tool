# 游戏化系统与金手指设计

技法源自《游戏入侵：抢男女主机缘会上瘾诶》(猫不秃, 1458章)的逆向拆解。

**核心判据**：这本书的金手指之所以能撑 1458 章，不是因为它强，而是因为它
**每次使用都是一段剧情、每次升级都是一次取舍、每次换舞台都会被清零一次**。
数值从不是卖点，"用规则赢过比你强的人"才是。

## 用法

- 设计新金手指 → §1 + §2
- 起名字 → §3
- 写面板文案 → §4 + §8 模板
- 后期崩坏 → §5 三大续命手段
- 写副本规则 → §6
- 投放世界观设定 → §7

## §1 金手指的五条判据

### 1. 金手指必须是"动词"，不是"数值"
好金手指是一个可无限重复的**动作循环**，而非一次性属性加成。

"盗"是动词，每次使用都是微型剧情：接近目标 → 创造机会 → 掷骰 → 处理后果。数值型金手指（+100力量）用一次就死。

**验收方法**：写下这句话——"主角每天都能对任何人做一次 X"。若成立且不腻，金手指成立。
可选动词：偷 / 换 / 借 / 抄 / 吃 / 记 / 赌 / 退货 / 翻新。

原文实证：
> `与其说虞寻歌在做任务，不如说她在当街溜子的同时，顺便做任务，虞寻歌会对每一个她遇到的NPC使用盗神天赋`

### 2. 低概率是爽点发生器，不是障碍
5%–30% 的成功率把爽感切成碎片，让作者能随时"发一颗糖"而不打破节奏；同时**失败本身也是内容**（吐槽、幸运值梗、玄学）。高概率技能会让作者失去发糖的颗粒度控制权。

> `少说也偷了一百多个NPC了，但就成功了三次。她幸运值是8！可就成功了三次！`
> `这难道就是所谓的越偷越幸运？！`

**做法**：核心技能成功率写在 5%~30%，并给出**提升概率的外部途径**（道具、幸运属性、改运技能）。读者的注意力会从"能不能成"转移到"怎么堆概率"——这正是升级流的引擎。

### 3. 限制即剧情发生器
好限制不是削弱，而是**指定主角必须做什么才能变强**，从而自动生成场景。

四类限制，各写一条：

| 类型 | 范例 | 逼出的剧情 |
|---|---|---|
| **资源代价** | 每次扣 20% 血量 | "床底磕药偷情侣"整章 |
| **次数上限** | 一生仅可使用一次 | 全书最大悬念资源（何时用？对谁用？） |
| **对象条件** | 无法对生命层次低于自己的生灵出手 | "她不能偷父母"，把亲情线锁进机制 |
| **痕迹条款** | 被窃者一天后才会想起丢东西 | 反侦察逻辑、销毁流程 |

**每写一条限制，追问"这条会逼主角去做什么？"——写不出答案的限制删掉。**

### 4. "一生一次"必须留卡 BUG 后门
终极限制若真是终极，就是死条款；若能被一次巧妙操作解锁，就变成主角"聪明"的证明，且能重复复用。

> `【盗神】下的第2条技能，仍旧是亮的……难道她游戏人物死亡，就算一生了？！`

设一条看似绝对的限制，再在**文本措辞里埋一个语义漏洞**（"一生"、"同一目标"、"当前世界"、"你的名字"），让主角靠**读条款**而非靠变强来突破。这是"智斗流"最便宜的高光。

### 5. 第一章就把天花板亮出来，然后立刻打脸
先给读者看到"顶配可能性"，再用一次惨败把它收回，形成全书最长悬念。

开篇 30 章内必须完成"金手指最强招的首次使用"，且结果为**半成功**：拿到残缺版 + 触发新规则 + 保留大招次数。

本书做法：抽 S 级 → 偷 SS 级城主天赋 → `【窃取成——检测到目标神赐天赋等级过高——盗窃中断！】` `【您已死亡】`
赔本赚吁喙，实则三重收益（残缺 SS 级【不朽】+ 刷新一生一次 + 亡灵种族天赋带回现实）。

## §2 等级与升级

### 双轨制：评级管稀缺感，阶位管战力
两者解耦后，可以写出"A 级天赋玩出 S 级效果"和"SSS 级技能的废物"，避免唯等级论、保住策略感。

- **评级**用字母（有限、稀缺、社交货币）：S / SS / SSS / SP
- **战力**用数字阶 + 情绪化称号（可无限延伸）：1–3阶傻瓜 / 4–6阶玩咖 / 7–9阶苦痛 / 深渊 / 魔王 / 霸主

反套路命名（"傻瓜/玩咖/苦痛"）自带幽默。**称号栏另设**（"呼吸有害""从容赴死""一语成谶"），是免费的世界观投放位。

天梯榜格式：`排名·姓名┃世界·种族┃战力┃称号`

> `这个技能不过是A级，可如果用得好，效果堪比S级`

### 升级 = 换玩法，不是数值翻倍
每次大升级写一张**得失清单**：新增 2 条、强化 1 条、**删除 1 条主角依赖的旧能力**。

删除项是关键——它制造新的战术难题，让升级后仍有仗要打。

本书 【盗神】(S) → 【一人派对】(SS) 的账本：
- 成功率 20%→30%，代价 20%血→10%血
- 新增"偷秘密"、新增【翻新】（分解重组道具）
- 新增【一人派对】——**从"偷东西"升维成"颁布规则"**
- **丢掉**"遗忘被动"、**新增**"同一目标最多成功十次"

### 套装 + 编号 = 最便宜的长线钩子
`(1/3)` 这个数字直接把"下一个在哪"变成读者的痒点，每收集一件就**改写自己的说明书**。

> `【索罗斯套装·面罩（1/3）】（A级）：……（注：每多收集一样索罗斯套装，隐蔽等级+1）`
> 后变为 `（2/3）……目前无法被S级以下道具探查成功`

**关键手法**：把部件**分配给不同的敌人/阵营**，让"收集"与"复仇"合并成同一条动作线。

## §3 命名公式：冷名挂天赋，热名挂技能

**天赋层**（冷、二至四字、意象化）：
【盗神】【不朽】【命运齿轮】【水神】【一人派对】【绝对自由】【欺诈之心】【凤凰座】【宿敌】【风不说话】

**技能层**（热、口语、长句、玩梗）：
【我要这个这个和这个】【盗神的盗，也可以是强盗的盗】【啊，我那个怎么不见啦】【甲来！】【出门在外，身份是自己给的】【我太想进步了】【我明明可以直接抢】【汗流浃背了吧】【我的喉咙里有辆摩托】【猫头鹰迷路了】【咔喳，锁死】【稳稳的幸福】【全家桶】【喝不完咖啡】【营养均衡】【浪费指南】【死性不改】

### 四条命名公式

1. **反差降维** — 把神级效果起个生活化名字：SSS 级时停叫【浪费指南】，SSS 级群攻叫【全家桶】，SSS 级追踪弹叫【营养均衡】
2. **第一人称台词化** — 技能名就是主角施法时会说的那句话：【我要这个这个和这个】【我明明可以直接抢】
3. **梗与流行语挪用** — 【汗流浃背了吧】【我太想进步了】【索罗斯套装】【孤僻的天线宝宝】
4. **同族命名成套** — 一个天赋下的技能共用一个语气人格；套装用编号；系列技能用同一意象递进（【猫头鹰怎么还不来】/【猫头鹰迷路了】/【猫头鹰被抓走了】）

**操作顺序**：写完机制后**先起最俗的口语名**，再把中二感全部收进天赋名和签名句。
名字里带"之""神""无上""破灭"的技能名一律降格为反差名。

### 天赋签名句：一句诗定义人格，技能名负责搞笑
一冷一热，避免全冷（说明书）或全热（廉价）。

> 【不朽】"你，即死亡"
> 【一人派对】"自由的灵魂永不困于名为高尚的荆棘……我们就是藏在阴影之中的贼，认清自己，而后尽情狂欢"
> 【宿敌】"命运将我们一次又一次推向对方，直至我们下定决心杀死彼此"
> 【风不说话】"风不说话，可它路过时你总会知道"
> 【傲慢之罪】"我无法忍受平庸，无论是我的，还是敌人的，赌一把，我赌我会赢！"

## §4 面板文案：三种排版，三种叙事节拍

**本书完全没有拟人化系统 AI**（"叮！"仅 5 次，"宿主"0 次）。系统没有人格，人格全部塞进**技能名**和**天赋签名句**里。

面板 = **【冷硬中括号】+ 官方文书句法 + 骚话技能名 + 括号内补充限制**

| 排版 | 格式 | 用法 |
|---|---|---|
| **说明式** | `【名】（等级）：正文……冷却时间X` | 长、静止、供查阅。**只在首次获得时全文出现**，之后一律只写技能名 |
| **播报式** | `——【提示语】` | 短句，破折号引导（全书 488 次）。连发**不超过 4 条**，制造"开箱感" |
| **喊招式** | `——【技能名】！` | 独立成段，加感叹号，充当战斗鼓点。每场战斗 **3–5 次，不要更多** |

播报式范例：
> `——【欢迎载酒星玩家虞寻歌首次激活进入世界战场的资格】`

破产式播报（全书最经典的三行反转）：
> `【赌上盗神的名义，您试图窃取亡灵族幽灵城城主奥尔洛夫·D血肉的天赋】`
> `【窃取成——检测到目标神赐天赋等级过高——盗窃中断！】`
> `【您已死亡】`

注意 `窃取成——` 被打断在半个词上的技法。

## §5 后期防崩坏：三大续命手段

### 手段一：换舞台并封印旧能力（清零式入场）
数值膨胀的根源是能力累积；解法是定期把主角**扉进一个禁用她全部积累的房间**。

> `她身上的装备被强制卸除，飞入她的游戏背包里上了锁，伪装技能全部消失，她变回了原本的模样`
> `打开游戏面板后发现，信息被简化到了极致`（只剩生命/法力/奥义/宠物/战力评级/一条天赋）
> 随后她的天梯榜排名是 **82679名，倒数第二**

**每 200–300 章设置一次清零式入场**：装备封印、技能封印、只准带 N 样东西进去。
主角的强度靠**选择哪 N 样**来体现，而不是靠数值。

### 手段二：换资源本位
数值一旦膨胀就不再是数值，而是新货币。每换一种本位，旧数值自动贬值为背景板。

本书的本位演进链：
```
金币/属性点 → 奥义 → 积木/门票/精力 → 魂火 → 时间线
```

其中**奥义**是最精妙的一步：`任何技能都可以消耗1点奥义来释放……D级技能可以有接近A级技能的威力` —— 一举把所有旧技能重新变得有用。

荒诞感是允许的，本身就是"旧本位贬值"的笑点：
> `【你获得了180个可支配属性点作为赔偿】` → `谁要属性点啊？！！`

### 手段三：把战斗换成游戏规则博弈
战力一旦到达主角够不着的层级，硬碰硬无法写。解法是让**规则本身成为战场**——弱者可以靠规则赢强者，战力差被机制吸收。

> `雾刃松瑰都知道她要找的是能将战力差距降至最低的游戏`
> `想要击杀这些15阶的玩家很难……这个游戏的唯一生路只有一个——存活到抚青风急收集到30块地图离开游戏`

同时把**天赋从"改变自己"升级为"改变规则"**：
> `在场所有等级超过100级的海妖禁用水系技能，一旦使用水系技能击中目标，需消耗2%生命值作为代价`（用规则秒杀 113 级 BOSS）

副本从"打怪"改成"带规则清单的游戏"，规则清单就是新的战斗招式表。

### 赛道演进链（全书骨架参考）
```
手机内测抽天赋(1-25章) → 现实副本+异族星球(26-250章) → 高塔/极夜城(250-370章)
→ 世界战场·神明游戏(373章起，占全书60%以上) → 竞技副本(900-1000章)
→ 埋骨之地·秩序时钟(1200-1380章) → 裁决游戏(1385-1458章)
```

## §6 副本规则清单的写法

**规则不是限制说明，是"武器货架"。** 读者读规则时就在猜主角会用哪条。

按五类各写 1–2 条：**收益条 / 惩罚条 / 禁用条 / 时钟条 / 优先级条**
其中**至少 3 条必须在本副本内被主角反向利用。未被利用的规则删掉。**

范例（春日迷宫 9 条规则节选）：
```
【每次击杀其他玩家，都能随机获得2块积木和一片当前地图的碎片，集限30片……才有资格离开迷宫】
【玩家被击杀时会被随机传送至迷宫36个入口之一，且随机掉落2块积木和一片地图碎片】
【一切技能作用于迷宫地图的技能都将无效】
【静止时间超过3分钟，玩家将被"点亮"，惩罚时间10分钟】
【每逢整点，迷宫将短暂开放3分钟……届时迷宫地图将会发生改变，旧地图碎片将会消失】
【迷宫规则高于游乐园规则】
```
主角随即精确利用其中三条。

### 留一条看不懂的规则
> `游戏规则一：ⅧΞΕΠΖΣΓΠΖΣⅪ`
> `游戏规则二：画作禁止出现红色`
> `游戏规则三：εδληκρΘΔηκΨΦΩζ`

**故意让主角看不懂两条规则**，把"完整设定"推迟到后面章节，同时制造紧张（`这些规则靠猜是根本猜不出来的`）。

副本/游戏名用零成本的期待感命名：滑雪大冒险 / 宝钻矿工 / 胡闹餐厅 / 积木与我 / 换牌 / 静谧群山 / 神明授课 / 埋骨之地。

## §7 世界观分层投放：四个喉舌

**任何设定块超过 300 字，拆成这四层分批投放；永远保留至少一条"看不懂的规则"当作下一段的钩子。**

| 层 | 密度 | 特点 |
|---|---|---|
| **NPC 口述** | 最松，带情绪 | 边解说边插科打诺，把硬设定稀释掉 |
| **道具说明** | 最密，可反复查阅 | 一行字建立一条资源管理规则 |
| **规则播报** | 信息量最大时用列表 | 编号列表 + 部分乱码 |
| **副本/游戏名** | 零成本 | 纯期待感 |

### 敌方天赋是最好的世界观投放器
庞大设定不靠旁白倾倒，靠**每个新角色带一份说明书进场**。一份天赋面板 = 人物性格 + 战斗方式 + 世界规则一角，三合一。

范例：赵书影【优雅永不过时】（A级）—— `你不是喜欢逃跑，你只是比别人更谨慎，对危机更敏感，当然，也活得更久`，四条技能【汗流浃背了吧】【优雅，永不过时】【别说我不想着你们】【我的喉咙里有辆摩托】。读完这 4 行，角色的喜剧人设、实用价值、和主角的交易关系全部到位。

**每引入一个重要配角，配一份四技能面板**：至少 1 条与主角金手指互补（可交易）、1 条构成克制（可制造麻烦）、1 条纯搞笑（塑造人格）。

### 克制关系要写成"技能条目"，不要写成"设定"
克制若只在旁白说明，读者无感；写成对方面板上的一条，读者能自己推演危险。

> 【咔喳，锁死】(SSS)(被动)：`任何SSS级以及SSS级以下的盗窃技对你使用时，其成功率都将降至0.000001%` —— **为主角量身定制的天敌条款**
> 【免费的才是最贵的】(被动)：主角被反偷，当场心理活动是"这技能是她的克星！第二反应：这技能和她有缘！"

**每隔 100–200 章，投放一个专门克制主角核心机制的敌人天赋，并让主角的第一反应是"我要抢它"。** 克制关系立刻转化为夺宝动机。

注意：【命运齿轮】只改幸运值、调换最高/最低属性，**没有任何攻击力却被评 B 级**，靠"恶心"制造了主角上辈子被活捉的结局——**评级要按"能造成多大麻烦"评，不按"能造成多少伤害"评。**

## §8 可直接复用的模板

### 天赋面板模板

## §9 系统设计自查表

- [ ] 金手指是**动词**，"主角每天都能对任何人做一次 X"成立
- [ ] 核心技能成功率在 5%–30%，且有提升概率的外部途径
- [ ] 写了资源代价 / 次数上限 / 对象条件 / 痕迹条款四类限制
- [ ] 每条限制都能回答"这会逼主角去做什么"
- [ ] 终极限制的措辞里埋了语义漏洞
- [ ] 开篇 30 章内完成了最强招的首次使用，结果为**半成功**
- [ ] 评级与战力**双轨解耦**
- [ ] 每次升级有得失清单，且**删掉了一条旧能力**
- [ ] 有 1–2 组编号套装，部件分配给不同敌人
- [ ] 天赋名冷、技能名热，签名句不解释机制
- [ ] 面板首次全文、之后只写名；喊招每场 ≤5 次；播报连发 ≤4 条
- [ ] 每 200–300 章有一次清零式入场
- [ ] 本位货币随舞台更换
- [ ] 副本规则五类齐全，且 ≥3 条被反向利用
- [ ] 保留了至少一条"看不懂的规则"
- [ ] 每个重要配角带一份四技能面板进场
- [ ] 每 100–200 章投放一个克制主角机制的敌人天赋
