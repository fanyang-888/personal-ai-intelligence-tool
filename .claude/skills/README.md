# 网文写作 Skills

从一部 1458 章 / 约 330 万字的中文网文（《游戏入侵：抢男女主机缘会上瘾诶》，作者：猫不秃）逆向拆解出的写作技法，整理为六个可按需触发的 skill。

所有规则都带**原文例证**和**可量化的配额参数**（字数、章数、密度、比例），而非泛泛的写作建议。

## 六个 skill

| Skill | 覆盖 | 什么时候会被触发 |
|---|---|---|
| **webnovel-opening** | 简介七段式、开局九节拍、黄金三章、报应时刻表 | 写简介/文案、写第一章、"开局不抓人""前三章没人看" |
| **webnovel-chapter-craft** | 60段骨架、断章六型、章节标题、章内节奏 | 写某一章、设计钩子、起标题、"读者不追更" |
| **webnovel-payoff** | 爽点十类、密度实测、憋屈上限、反派破防、金句、幽默 | 设计爽点/打脸/复仇、"剧情平淡""看腻了""主角太憋屈" |
| **webnovel-system-design** | 金手指五判据、等级双轨、命名公式、面板文案、副本规则 | 设计主角能力、写技能说明、起名、"金手指没用几章就废""数值膨胀崩了" |
| **webnovel-characters** | 人设七零件、独狼五管线、反派/女性对手、叙述腔调、对白三职能 | 设计人设、写对白、"人物立不起来""角色分不清" |
| **webnovel-arc-structure** | 全书骨架配比、副本九环节、结算六件套、伏笔、主线换挡 | 规划大纲、设计副本、安排伏笔、"写到几百章卡住了" |

## 交叉引用

同一个问题常常跨 skill：

- **写开局** → `webnovel-opening` + `webnovel-system-design`（金手指首发）
- **写一章** → `webnovel-chapter-craft`（骨架）+ `webnovel-payoff`（密度自查）
- **副本结算章** → `webnovel-arc-structure`（六件套）+ `webnovel-payoff`（数值播报后必接吐槽）
- **新角色登场** → `webnovel-characters`（四拍模板）+ `webnovel-system-design`（配一份四技能面板）
- **后期写不动** → `webnovel-system-design`（三大续命手段）+ `webnovel-arc-structure`（主线换挡）

## 注意

- 这些是**类型写作的工程方法**，不是文学价值判断。规则的目标是连载黏性与读者留存。
- 例证全部为技法说明用途的短句引用，不构成对原作的替代。
- 套用时**换设定、换人物、换世界观**——抄的是结构与节奏，不是内容。
