# 网文开局与简介工程

技法源自《游戏入侵：抢男女主机缘会上瘾诶》(猫不秃)的逆向拆解。核心判据：**开局的每一句话都在买读者的下一分钟**。

## 用法

先判断用户要哪一层，再执行对应清单：
- 要**简介/文案** → 走 §1
- 要**第一章** → 走 §2 + §3
- 要**前三章** → 走 §2 + §3 + §4
- 要**诊断已有开局** → 用 §5 检查表逐条打分

---

## §1 简介的七段式结构

按顺序写，每段一个独立转化功能，不可合并：

| 段 | 内容 | 功能 |
|---|---|---|
| ① 标签行 | `【题材+cp状态+流派+主角属性+核心设定】（又名：xxx）` | 5 秒完成"我看不看"筛选；"又名"抢搜索词 |
| ② 开局动作 | 主角第一个决定性动作，**带道具、带对象、带后果** | 用具体到荒诞的动作代替剧情概括 |
| ③ 前世真相 | 一句话完成"背叛 + 身份降维"双重击打 | 建立恨意与格局 |
| ④ 角色宣言 | 三行短句，各自独立成段 | 读者代入契约 |
| ⑤ 分隔符 | `———` | 从"人物"视角切到"世界"视角 |
| ⑥ 名号轰炸 | 世界播报 + 12~20 个未来称号 → 落到真名 | 把简介变成"未来剧透彩票" |
| ⑦ 避雷注释 | `（注：不是X┃不是Y┃我喜欢写Z）` | 预期管理，前置过滤差评 |

### ②开局动作：写动作，不写身世
❌ "她重生回到了灾难前一年。"
✅ 原文：`虞寻歌重生后第一件事就是回家给弟弟灌了瓶白的，让他错过第一次游戏内测。`

差别在于：后者有**具体道具（白酒）、明确对象（弟弟）、可推演的后果（错过内测）**，读者立刻知道这本书的乐趣类型是"搞事"而非"打怪"。

### ③身份降维式真相句
让主角发现自己**在别人的故事里只是个功能性角色**，比单纯"被背叛"多一层羞辱，恨意翻倍。

> `上辈子直到临死才知道他一直躲在背后算计自己，而自己只是一本男频赘婿爽文的反派...她遭受的种种恶意都是他在背后甩锅。`

正文补刀写法（自嘲+破防）：
> `弥留之际才知道自己原来只是一本书里的反派……还是暗恋虞寻欢这个男主的偏执姐姐。好好好，想要赶时髦又碍于规矩不能写骨科你就这么恶心人是吧？！`

**要点**：给主角一个"叙事层"的敌人——不只是有人害她，是整个故事结构在害她。复仇因此升级为"改写文本"。

### ④三行宣言 = 读者代入契约
读者要在简介里拿到三个答案，各一行：

```
「立场反转句」   → 我恨谁、我这辈子换什么活法
「欲望宣告句」   → 我要什么
「行动纲领句」   → 我用什么方法（必须是可执行动词串）
```

原文：
> `这辈子换我躲在背后了。`
> `你们的机缘我都要了。`
> `参加内测，重抽天赋，背后搞事！`

第三句是关键——三个动词让读者知道**每一章会看到什么**。

### ⑥名号轰炸法
把未来 100 万字的高光时刻压缩成一串**未解释的称号**。读者是为"解锁称号"而追更。

写 12~20 个，**四类混排**，禁止全部同一情绪：

1. **权柄类**（给身份高度）：载酒裁决、星海的救世主
2. **所有权/创作者类**（暗示拥有奇物）：【暴躁月亮】主人、【猫的理想】船长、【雪国回音】制作者
3. **搞笑贬损类**（降温、防中二）：窝囊气球制造商、游戏入侵也要单机的单机爱好者、战场聊天频道八卦中心
4. **因果事件类**（最强钩子，暗示引发过大事）：机械族第二次大罢工导火索、群山的大灾变
5. **宿命悲情类**（收尾拔高）：入侵序列之外的无罪之人、世界叹息书写者、打完一阶段还有二阶段的星海囚徒

**排列节奏**：严肃 → 搞笑 → 搞笑 → 严肃 → 荒诞 → 悲壮 → **真名收尾**。
至少 3 个必须荒诞得像笑话；最后 2-3 个转悲壮；末位落真名（`——载酒寻歌！`）。

每个称号都必须是一个**未解释的谜题**（"猫的理想"是什么？"沉默的饼干国王"是什么？）。

### ⑦避雷注释
列出你预判会被骂的 3-4 个点，用"不是X"句式声明。竖线 `┃` 分隔比顿号信息密度更高。

> `（注：不是无情人设┃不对蓝星出手┃不是无私奉献型┃很多女反派/对手，我喜欢写）`
> `（不要拉踩，求你！・ࡇ・）`
> `（角色无任何原型）`

## §2 第一章前 500 字的九节拍

**顺序本身就是技法**。照抄这个序列：

1. **睁眼 + 错位感** — 给一个与死亡场景冲突的物件（`名贵华美的吊灯`）
2. **死法即仇人** — 第 2-3 句同时抛出"我怎么死的"和"谁杀的我"
3. **能力落差** — 先证明她曾是强者，再剥夺
4. **仇人二号在场** — 现场立刻有第二个可恨的人
5. **时间锚点** — 精确到时分的日期，确认重生
6. **世界规则倾泻** — 核心设定 2-3 句说完
7. **信息差折现** — 把规则立刻折算成命运差价
8. **道德定位声明** — 提前划清"这不是圣母文"
9. **倒计时任务** — 一个 X 小时后的死线

**500 字内必须交付**：重生点、死法、仇人名、末日日期、金手指规则、主角道德坐标、一个倒计时。
**500 字内禁止出现**：环境描写、外貌描写、回忆插叙超过两句。

### 各节拍的原文范本

**节拍2｜第二句就报仇人全名和死法**
> `她不是被虞寻欢钉在地牢的法阵里放血吗？`

必须是「反派专名 + 具体施虐动词」。"放血""钉在法阵里"不可替换成"害死"——具体动词才有痛感。

**节拍3｜先证明强，再剥夺**
> `只一秒，她便条件反射地调动体内能量，一整年的逃亡经历让她身体已形成本能……然而她一个帅气的鲤鱼挺身，无事发生……体内的反应告诉她，她现在就是个普通人。`

一个"高手本能动作 → 失败"同时交代了前世经历、战斗风格、当前处境。

**节拍7｜信息差折现**
> `而参加过这内测的玩家，有的终生都在悔恨自己当初只玩了几分钟，有的则一飞冲天从鱼变龙，而她那位好弟弟就是一飞冲天的那一个。`

**节拍8｜道德定位声明**
> `不过她没兴趣拯救世界告诉所有人，异族入侵在诸多限制下有一个还算漫长的过程，在这个过程中，死在同类手上的人可比死在异族手上的人多多了。`

**节拍9｜倒计时**
> `而2月22日2点22分，便是第一次内测！`
> `离游戏内测还有不到三小时，她必须赶回家阻止虞寻欢玩这个游戏。`

全章反复报时间（`23点` → `1点47` → `2:22`）。重生/穿越开局必须在 1000 字内给出"X 小时后发生 Y"。

## §3 断章：黄金三章的收尾

这本书的开局**几乎不用"危机悬念断"**，而是用"下一份收益还没数完"留人。五种可用类型：

| 类型 | 原文范本 |
|---|---|
| **最高奖品断** | `神赐天赋更是整个蓝星唯一一个SS级……最后更是盯上了她的神赐天赋。` |
| **情绪反转断** | `5分钟前：当小偷不好吧？` / `5分钟后：我就要！！！` |
| **自嘲金句断** | `还是得再当一回街溜子，啊不，盗神。` |
| **面板延迟断** | 本章拿到 SS 级天赋，但**技能说明留到下一章开头**才展示 |
| **清单中断断** | 断在采购清单的半截，下一章接着列 |
| **报应落地断** | `虞寻歌：奈斯啊！！五十斤黄金没白花！！！` |

## §4 前三章必须完成的三个动作

### A. 信息差要在同章内兑现成现金
"知道未来"本身不是爽点，"**因为知道未来所以现在多拿了一样东西**"才是。

建一张「先知信息 → 兑现物」对照表。**禁止出现"她知道但暂时用不上"的信息超过两章。**

原文范例：
- 知道可以删号重抽 → 当场删号十几次抽到 S 级【盗神】
- 知道亡灵有双种族天赋 → 选亡灵，卡 BUG 把种族天赋带回现实
- 知道未来货币崩盘 → 全部换黄金

### B. 金手指第一次使用就必须"卡 BUG"
主角赢一次不够，要赢得**超出规则**，读者才有智力优越感。

写完技能说明后，**立刻找说明里的字面漏洞**，让主角第一次使用就钻进去：
> `"一生仅可使用一次一次"？难道她游戏人物死亡，就算一生了？！所以？所以！所以这意味着，她还能使用一次如此逆天缺德的天赋？！！！`

第 2-4 章内必须完成一次"读者没想到、但规则允许"的操作。

### C. 金手指要自带缺德感和可量化成本
能力若无成本，爽感衰减。给核心技能一个可量化的资源代价（血量/寿命/记忆），让每次使用变成小赌博：
> `你可以对同一个人重复使用技能，但从第二次开始，每一次盗窃都会扣除你20%血量。`
> `连偷4次，偷得脸色发白，血量降到20%，磕了一瓶初级疗伤药剂，血量回到80%，继续！`

"趴床底吃肉干回血继续偷"——这就是把金手指变成**可反复消费的日常桥段**。

## §5 恨意与报应的调度

### 反派用"付出证据"钉死，比用恶行钉死更狠
先列举反派对主角的种种好，再一条条揭穿这些好的成本由主角自己承担。读者的恨来自**被骗**，不是被打。

- 感动细节要写得真诚到读者也会被骗：`有好吃的他会等着虞寻歌回家一起吃……然后就在今年年初给虞寻歌买了别墅，别墅还落到虞寻歌名下`
- 揭穿句用反问 + 感叹号连打：`就那栋把她感动地稀里哗啦的别墅，用得是自己给他的钱！落自己名下不应该吗？自己的钱买了个自己的别墅，她到底在感动什么？！`

### 给压迫机制下"定义句"
每 5-10 章插入一句**结构性总结句**，用比喻而非心理术语。这类句子是全书的传播点（读者会截图转发）：
> `低段位的压榨是全家一起PUA，高段位的压榨都是组合拳，一个人负责打一个人负责疗伤一个人负责端茶倒水让她缓口气儿。`
> `虞清山和虞寻欢就像最顶尖的钓鱼好手，他们要大鱼，就会给上好的饵料，时不时还会放长鱼线让鱼儿放松警惕。`

### "不能一刀了结"的声明
读者最怕"重生开局杀反派"导致故事结束。主角必须自己论证为什么不杀——**情绪理由在前，战略理由在后**：

> `一刀泯恩仇？不存在的……她不要向前看，她要向下看，她要将虞寻欢死死踩在脚下，让他只能看着自己的鞋底`
> （随后补）`她无法凭她一个人的力量同时对抗苏梁韩三家，最好的办法自然是打入内部`

只有战略理由 → 主角显得冷血；只有情绪理由 → 主角显得蠢。两个都要，顺序不能反。

### 报应时刻表
**每个反派登场后 10 章内必须领第一份报应。** 做一张三列表：

| 反派 | 登场章 | 首次报应章 | 报应形态 |
|---|---|---|---|
| 柳争流 | 第1章 | 第6章 | 被操控的尸体栽赃入狱 |
| 梁鱼川 | 第10章 | 第12章 | 断右小臂 |
| 虞寻欢 | 第1章 | 第14章 | 被枪王腰斩 |
| 苏一瞳 | 第8章 | 第19章 | 割耳 |

报应形态要**身体化、可视化、不可逆**（断臂、割耳、腰斩），而不是"破产""名声扫地"。

## §6 两个可直接套用的结构性选择

**A. 反派视角的重生** — 主角不是要拯救世界，而是要抢走男女主的所有机缘。这解决了重生文最大的动力问题：每一次行动**同时给自己加分、给敌人减分**，一份笔墨换两份爽感。

**B. 潜伏在仇人身边** — 主角明明有能力翻脸，却选择继续演戏（`她笑得比柳争流更亲热`）。让每一次家庭聚餐都变成高压戏，并形成核心爽点结构：

> **明面损失（送礼、装穷、被要钱）× 暗面收割（偷属性、偷道具、断肢）= 同一场景双重收益**

## §7 开局诊断检查表

给已有开局逐条打分（每条 0/1）：

- [ ] 简介第一句是**具体动作**而非身世概括
- [ ] 简介里有**三行独立成段**的角色宣言
- [ ] 简介有**未解释的称号/谜题**至少 5 个
- [ ] 简介末尾有**避雷注释**
- [ ] 第 1 章前 3 句出现**反派专名 + 具体施虐动词**
- [ ] 第 1 章前 500 字**没有**环境/外貌描写
- [ ] 第 1 章给出了**精确到分钟的倒计时**
- [ ] 第 1 章声明了主角的**道德坐标**（是否救世/是否圣母）
- [ ] 前 3 章内先知信息**已兑现**为至少 3 件具体收益
- [ ] 前 4 章内金手指**卡过一次 BUG**
- [ ] 金手指有**可量化的使用成本**
- [ ] 每章结尾属于 §3 六种断章类型之一
- [ ] 主角论证过"为什么不直接杀"，**情绪理由在前**
- [ ] 首个反派在第 10 章前领了**身体化的报应**

低于 10 分的开局，优先补：具体动作句、倒计时、信息差折现。
